# 建立静态工具目录的最小可浏览页面

Status: done

## Parent

.scratch/src-data-catalog-page/PRD.md

## What to build

交付一个最小但完整的静态工具目录页面：用户可以打开页面，看到从本地工具数据和标签数据规范化后的工具列表、关键统计、每个工具的标签名，以及官网和 GitHub 外链。页面需要沿用 XAlbum 当前的工具图谱视觉语言，不依赖外部 API，并且能在数据字段稀疏时继续稳定展示。

## Acceptance criteria

- [x] 用户可以访问一个新的工具目录页面，并看到工具总量、标签总量、官网覆盖量、GitHub 覆盖量等基础统计。
- [x] 页面展示工具列表，每个条目至少包含工具名、关联标签名、官网入口，并在存在 GitHub 链接时展示 GitHub 入口。
- [x] 原始标签 ID 字符串会被转换为人类可读的标签名，普通用户不会看到裸数字标签 ID。
- [x] 缺失描述、缺失 GitHub、空 category ID 或稀疏字段不会导致页面崩溃或条目消失。
- [x] 外部链接使用安全的新标签页打开方式。
- [x] 数据规范化逻辑有测试覆盖，包括正常标签解析、空标签、缺失可选字段和覆盖量统计。
- [x] 页面可见行为有测试覆盖，至少验证统计、工具名、标签名和外链入口会渲染出来。
- [x] 类型检查和生产构建通过。

## Blocked by

None - can start immediately
